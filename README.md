# EKT Assistant — HackAlem AI

Прототип консультанта по электротехнике для ekt.kz. Команда Ah Shit, Here We Code Again.

## Текущий статус

Первый рабочий этап, НЕ готовое выполнение всего кейса. Реальный каталог; демонстрационная корзина, не связанная с заказами ekt.kz. Допустимость этой интеграции уточняется у партнера.

Реализованы: поиск по первым 10 страницам каталога (репрезентативная выборка), свежие карточки и складские остатки, характеристики и ссылки на сертификаты при наличии доступного поля, предупреждение о выявленном расхождении номинального тока, контекст последних найденных товаров, адаптивный интерфейс, предложение и отдельное подтверждение добавления, актуальная ссылка на демонстрационную корзину. При подтверждении повторно проверяются цена, остаток, кратность и уже добавленное количество. Предложения одноразовые, действуют 5 минут и привязаны к сессии.

Опционально подключается OpenAI Responses API. Без API-ключа интерфейс явно показывает режим поиска по каталогу; это не выдаётся за полноценного ИИ. Вызовы модели пока не проверены с реальным ключом.

ЕЩЁ НЕ РЕАЛИЗОВАНЫ: загрузка Excel/Word/PDF/JPEG; подбор релевантных аналогов; проверенная база условий оплаты/доставки; интеграция с реальной корзиной и платформой сайта; долговременное хранение; казахский язык. Сертификат распознается только как HTTPS-ссылка в свойстве с маркером CERT/SERT/СЕРТИФ; реальные варианты этих полей требуют дополнительной проверки. Скорость модели ещё не измерена.

## Запуск

Python 3.10+ с рабочими корневыми TLS-сертификатами. Сервер и UI используют стандартную библиотеку Python и обычный JavaScript; сборка UI не требуется.

```sh
cp .env.example .env
# Заполните EKT_API_USER и EKT_API_PASSWORD доступами партнера.
# При наличии ключа заполните OPENAI_API_KEY; OPENAI_MODEL можно изменить.
python3 server.py
```

Откройте http://127.0.0.1:8765. Дождитесь загрузки каталога. PORT по умолчанию 8765. Доступы к каталогу судьи получают от партнера; в репозитории их нет. OpenAI-режим требует действующего API-ключа и доступной модели (по умолчанию gpt-4.1-mini). До сдачи команда обязана организовать демонстрационный доступ для жюри без личных аккаунтов участников.

На macOS при ошибке проверки SSL установите корневые сертификаты для своей установки Python (обычно через поставляемый с Python Install Certificates.command). Не отключайте проверку TLS. На рабочем компьютере запуск проверен Python из окружения Codex.

## Проверка сценария

1. Введите `200300285_`. Должны появиться карточка Legrand, остатки и предупреждение о конфликте 160/250 А в источнике. Эти значения взяты из API, а не сгенерированы.
2. Выберите количество и нажмите «Подготовить добавление». Корзина еще пуста.
3. Нажмите «Отмена»: корзина не меняется. Повторите и нажмите «Да, добавить»: появится ссылка на /cart.
4. Откройте ссылку: она показывает товары текущей сессии. В другом браузере — другая корзина.
5. Попробуйте количество выше остатка: сервер отклоняет добавление. При изменении цены требует новое предложение.

```sh
python3 -m unittest discover -s tests -v
```

9 тестов проверяют отсутствие неявных изменений, одноразовое согласие, повторную проверку остатков, учет существующей корзины, изменение цены, истечение предложения, изоляцию сессий и некорректные количества.

## Архитектура и данные

`static/` — адаптивный чат и страница корзины. `server.py` — HTTP-сервер, read-only клиент ekt.kz, поиск, необязательный клиент OpenAI и серверные операции корзины. `tests/` — проверки правил корзины. `docs/` — требования и архитектура.

API каталога: https://ekt.kz/api/products?page=1 и https://ekt.kz/api/products/detail?id=515291. Basic Auth только на сервере. Поиск ограничен 10 страницами; неизвестный товар не означает, что его нет во всем каталоге. Перед ответом и подтверждением карточки запрашиваются заново. Снимок данных актуален только на момент запроса; корзина ничего не резервирует.

Сессии, история и корзины находятся в памяти, истекают через 2 часа бездействия и теряются после перезапуска. Сервер слушает только 127.0.0.1, предназначен для локальной демонстрации. Публичное размещение требует HTTPS, защищенных cookies, ограничения запросов и production-сервера. Платежные данные не запрашиваются. История не записывается на диск; при включении модели последние сообщения и найденные карточки передаются в OpenAI с store=false. Не вводите в демонстрацию конфиденциальные сведения.

`.env` исключён из Git. Не включайте ключи в коммиты, скриншоты или README. Для ИИ использован API по официальной документации: https://developers.openai.com/api/docs/quickstart . Код создан командой с помощью Codex; сторонние библиотеки приложения на этом этапе не используются.
