# Размещение демонстрации на Render

Состояние: конфигурация подготовлена; наличие этого файла не означает, что сайт уже опубликован.

1. Отправьте подготовленный код в `main` выданного репозитория.
2. Войдите в https://dashboard.render.com/ своим аккаунтом. Подключите только нужный репозиторий `BAITC-Hacks/hack-71f6ba34-ah-shit-here-we-code-again`. Если организация запрещает установку приложения Render, нужен доступ от администратора организации; не меняйте видимость репозитория.
3. New → Blueprint → выбрать репозиторий и `render.yaml`. Выбран Free; платный тариф без согласия команды не подключать. Альтернативно Web Service: Python 3, Build Command `env PUBLIC_MODE=0 HOST=127.0.0.1 python -m unittest discover -s tests -q`, Start Command `python server.py`, Health Check `/healthz`, переменные из YAML.
4. В защищённых переменных Render заполните `EKT_API_USER`, `EKT_API_PASSWORD`, `OPENAI_API_KEY` значениями из локального `.env`. Не копируйте `.env` в репозиторий и не присылайте секреты в чат. Хостинг получает эти значения для выполнения серверных запросов; браузеру они не передаются.
5. Задайте отдельный случайный `DEMO_ACCESS_CODE` не короче 24 символов, как минимум с 10 разными символами, без пробелов и двоеточий (например, случайный пароль из менеджера паролей). Это пароль входа в демонстрацию, НЕ ключ OpenAI. Ссылка и логин `jury` с этим кодом передаются жюри через закрытое поле сдачи/канал организаторов. Не размещайте код в публичном README.
6. После Deploy дождитесь Live. Откройте HTTPS-ссылку Render, введите `jury` и код. Проверьте статус подключения ИИ и каталога, запрос `200300285_`, файл, поиск аналога и подтверждение корзины. Сам статус Live не подтверждает доступность внешних API.
7. Внесите действительную ссылку в материалы сдачи. Автопубликация из Git отключена: после дедлайна нельзя менять оцениваемую версию. Последний нужный deploy выполняется до дедлайна.

## Ограничения размещения

- Бесплатный сервис засыпает после 15 минут без входящих запросов. Первый запуск после сна занимает около минуты. Сообщите жюри об этом. Источник: https://render.com/docs/free .
- Корзины, история и счётчики ограничений хранятся в памяти одного процесса и сбрасываются при сне, рестарте или новом deploy. Это демонстрация, не магазин с долговременными заказами. Не запускайте несколько процессов/реплик без общего хранилища.
- HTTPS обеспечивает Render. Не открывайте Basic Auth через незащищённый публичный HTTP. Код демонстрации защищает от случайных посетителей, но любой знающий его может пользоваться общим лимитом.
- Ключ OpenAI оплачивает запросы из ресурсов владельца проекта. Ограничения приложения сокращают использование, но не являются гарантированным лимитом расходов в долларах; учёт сбрасывается при рестарте. При необходимости остановить доступ — остановите сервис или отзовите выделенный ключ.
- Используется стандартный HTTP-сервер Python за прокси Render, рассчитанный здесь на ограниченную демонстрацию. Для массовой эксплуатации нужны production-сервер, общее хранилище и защита от перегрузки.

Официальная документация: https://render.com/docs/web-services , https://render.com/docs/blueprint-spec , https://render.com/docs/git-provider .


Ограничения в `render.yaml`: `OPENAI_DAILY_CALL_LIMIT=100` — не более 100 попыток обращения к OpenAI за сутки UTC на процесс; `SESSION_REQUESTS_PER_MINUTE=12` — не более 12 запросов чата/файлов/подготовки/подтверждения в минуту на сессию. При достижении лимита ИИ остаются карточки каталога; загрузка файла сообщает ошибку лимита. Это технические ограничения запросов, не денежный бюджет.
