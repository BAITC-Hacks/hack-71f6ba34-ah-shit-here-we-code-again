## Первоначальная проблема с запуском на Windows

Первоначально ручная проверка на Windows была заблокирована: на `127.0.0.1:8765` не был запущен сервер, а в рабочей среде команды `python` и `py` были недоступны; файл `.env` также не был обнаружен. Позднее подтверждено, что Python установлен на компьютере, но его путь не был доступен среде проверки. Это не относится к проверке, выполненной на Mac другого участника.
