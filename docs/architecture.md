# Архитектура прототипа EKT Assistant

Статус: проектирование во время хакатона, реализация начата. Этот документ не подтверждает наличие готовых функций.

Браузерный чат → сервер приложения → read-only API каталога ekt.kz.
Секреты доступны только серверу через переменные окружения; не публикуются в GitHub.
Поиск по репрезентативной выборке → получение актуальной карточки → ответ с источником.
LLM используется для консультации по предоставленным данным. Модель не изменяет корзину непосредственно.
Сервер выдает предложение с конкретным товаром и количеством; пользователь отдельно подтверждает его.
Перед добавлением сервер повторно проверяет остаток. Предложение одноразовое, привязано к сессии.

API настоящей корзины партнером не предоставлен. Для проверки поведения создается явно обозначенная демонстрационная корзина, не оформляющая заказы ekt.kz. Приемлемость такого режима необходимо уточнить у ментора.

Обнаружено противоречие в карточке 515291: название/описание 160А, свойство NOMINALNYY_TOK 250 А. Нельзя скрывать расхождения и обещать техническую совместимость без проверки.

Приоритет: каталог и ответы → подтверждение и корзина → вложения → запуск и проверки → сдача.
